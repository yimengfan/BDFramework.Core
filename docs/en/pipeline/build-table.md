# Table Building

The complete Excel → SQLite flow, producing the read-only client database `local.db` and the server database `server.db`.

## Entry points

```csharp
namespace BDFramework.Editor.Table

public enum DBType { Local, Server }

public static class BuildTools_Excel2SQLite
{
    public static bool BuildSqlite(string ouptputPath, RuntimePlatform platform,
                                   DBType dbType = DBType.Local, bool isUseCache = false);
    public static bool Excel2SQLite(string excelPath, DBType dbType, bool isForce = false);
    public static void BuildTableForBatchMode();                 // BatchMode 入口
    public static void CopySqlToOther(string root, RuntimePlatform sourcePlatform);
    static public void CollectTableTypes();                      // 扫 Game.Data.* 类型
}
```

`BuildTableForBatchMode()` does Local first and then Server; if either fails it `throw new Exception("【CI】构建 client.db/server.db 失败! ...")`.

## Excel format conventions

File discovery: walks `Assets/*/Table/**/*.xlsx` (`ExcelEditorTools.EXCEL_PATH = "Table"`).

!!! warning "Only `.xlsx` is supported"
    `.xls` and `.csv` are not supported. `GetAllExcelFiles(exceltype = "*.xlsx")`.

### Structure

| Row | Content |
|----|------|
| **Row 1** | Comment row (**skipped**, `skipLine = 1`) |
| **Row 2** | Optional `server` / `local` marker row |
| **Header row** | The **first row within the first 10 rows whose cell equals `"Id"`** = the field name row |
| **Type row** | The row **above** the header row |
| Data rows | Every row after the `Id` row |

```text
┌──────┬──────────┬──────────┬──────────┐
│ 备注 │ 英雄ID   │ 名字     │ 属性     │   ← 第 1 行：备注，被跳过
├──────┼──────────┼──────────┼──────────┤
│      │ int      │ string   │ int[]    │   ← 第 2 行：类型行（或 server/local 标记行）
├──────┼──────────┼──────────┼──────────┤
│      │ Id       │ Name     │ Skills   │   ← 表头行（含 "Id" 的行）
├──────┼──────────┼──────────┼──────────┤
│      │ 1        │ 剑士     │ [1,2]    │   ← 数据行
└──────┴──────────┴──────────┴──────────┘
```

### `server` / `local` marker rows

When the first column of row 2 matches `server` or `local` in lower case, **`*` retention mode** is entered:

- Only columns whose value in that row is `*` **are retained**
- A data row is retained only if its first column is `*`
- When a server row exists `skipLine = 3`; otherwise it prints `【无server local模式】`

This is used for the "one Excel file produces both the local table and the server table" scenario.

### Type support

| Type | Description |
|------|------|
| `int` / `float` / `double` / `string` / `bool` | Basic types |
| `xxx[]` | Array, written as `[a,b,c]` in Excel |
| `list<xxx>` | List |

Defaults for empty cells: numeric `0`, `string` `""`, `bool false`, arrays an empty array.

String array parsing includes quote repair, and reports an error when the quote count is odd.

!!! warning "The first column must be `Id`"
    If `Id` cannot be found → `Debug.LogError("表格数据可能有错,没发现Id字段,请检查")` and returns `("{}", false)`.

### Multiple Sheets

The **first** sheet is read. When multiple sheets share the same structure they are merged automatically. `mSheet.Rows.Count < 1` fails immediately.

## Generated C# table classes

`Excel2CodeTools` turns Excel into POCOs:

| Item | Convention |
|----|------|
| Generated location (local table) | `Assets/Code/Game/Table/Local/<Name>.xlsx.cs` |
| Generated location (server table) | `Assets/Code/Game/Table/Server/<Name>.xlsx.cs` |
| Generated into Resource_SVN | `Assets/Resource_SVN/Table/Code/` |
| Namespace | `Game.Data.Local` / `Game.Data.Server` —— **must have the `Game.Data.` prefix** |
| Generated header | `// <auto-generated> // Genera by BDFramework` |
| Hotfix marker | `HotfixFileConfigLogic.IsHotfixFile()` decides whether `<Name>.xlsx.cs` or `<Name>.xlsx@hotfix.cs` is generated |

```csharp
// 生成结果示例（Assets/Code/Game/Table/Local/Hero.xlsx.cs）
namespace Game.Data.Local
{
    [Serializable()]
    public class Hero
    {
        [PrimaryKey] public int Id { get; set; }
        public string Name { get; set; }
        public string Level { get; set; }
        public int StarLevel { get; set; }
        public int NextLevel { get; set; }
        public string[] AttributeName { get; set; }
        public int[] AttributeValue { get; set; }
        public int[] Skills { get; set; }
    }
}
```

!!! danger "Changing the namespace breaks table export"
    `BuildTools_Excel2SQLite.CollectTableTypes()` collects types by `Namespace.StartsWith("Game.Data.")`.

!!! danger "The table name is the class name, without the namespace"
    `TableQueryForILRuntime` generates SQL from `type.Name`. **Classes with the same name in different namespaces collide on the same table.**

## Incremental build

Per-file MurmurHash3 comparison against `TableLog.Hash`; identical files are skipped:

```text
【Excel2Sql】内容一致,无需导入
```

`TableLog` schema: `Path` / `Hash` / `Date` / `UnityVersion`.

`BuildSqlite(..., isUseCache: true)` controls whether the cache check is enabled.

## Artifacts and encryption

| Artifact | Path | Encryption |
|------|------|------|
| client DB | `<root>/<platform>/local.db` | **SqlCipher-encrypted** (`SqliteLoder.Password`) |
| server DB | `<root>/server_data/server.db` | **Not encrypted** |
| build info | `<root>/<platform>/package_build.info` (writes `tableSVC`) | — |

The exact words in `LoadServerDBOnEditor`:

```csharp
BDebug.Log("Server.db 不使用加密,否则服务器不好处理!!!");
```

It **must not be encrypted**, otherwise the server side would need to integrate SQLCipher just to read it.

## Runtime reading

```csharp
// 单条件
var hero = SqliteHelper.DB.GetTableRuntime().Where("id = {0}", 1).FromAll<Hero>();

// 多条件
var ds = SqliteHelper.DB.GetTableRuntime().Where("id > 1").And.Where("id < 3").FromAll<Hero>();

// 排序 + 限制
var top = SqliteHelper.DB.GetTableRuntime().OrderByDesc("level").Limit(10).FromAll<Hero>();
```

## Common failures

| Symptom | Root cause |
|------|------|
| `表格数据可能有错,没发现Id字段,请检查` | No cell within the first 10 rows equals `"Id"` |
| Queries return nothing after export | The table class namespace is not `Game.Data.*` (so `CollectTableTypes` never collected it) |
| `SQLiteException: file is not a database` | Wrong password (`GameCipherConfigProcessor.Config.SqlitePassword`) |
| Two tables overwrite each other's data | Classes with the same name in different namespaces (table name = class name) |
| Every import is a full import | The hash cache went stale (`TableLog` was cleared, or `isUseCache: false`) |
| Array fields are empty | The Excel format is not `[a,b]`; or the quote count is odd |
| The server cannot read server.db | Encryption was applied by mistake (server.db **must not be encrypted**) |
| `.xls` files have no effect | Only `.xlsx` is supported |
