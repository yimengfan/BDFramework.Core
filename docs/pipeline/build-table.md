# 表格打包

Excel → SQLite 的完整流程，产出客户端只读库 `local.db` 与服务器库 `server.db`。

## 入口

```csharp
namespace BDFramework.Editor.Table

public enum DBType { Local, Server }

public static class BuildTools_Excel2SQLite
{
    public static bool BuildSqlite(string ouptputPath, RuntimePlatform platform,
                                   DBType dbType = DBType.Local, bool isUseCache = false);
    public static bool Excel2SQLite(string excelPath, DBType dbType, bool isForce = false);
    public static void BuildTableForBatchMode();                 // BatchMode 入口
    public static void CopySqlToOther(string root, RuntimePlatform sourcePlatform);
    static public void CollectTableTypes();                      // 扫 Game.Data.* 类型
}
```

`BuildTableForBatchMode()` 先 Local 后 Server，任一失败 `throw new Exception("【CI】构建 client.db/server.db 失败! ...")`。

## Excel 格式约定

文件发现：遍历 `Assets/*/Table/**/*.xlsx`（`ExcelEditorTools.EXCEL_PATH = "Table"`）。

!!! warning "只支持 `.xlsx`"
    不支持 `.xls` 或 `.csv`。`GetAllExcelFiles(exceltype = "*.xlsx")`。

### 结构

| 行 | 内容 |
|----|------|
| **第 1 行** | 备注行（**被跳过**，`skipLine = 1`） |
| **第 2 行** | 可选的 `server` / `local` 标记行 |
| **表头行** | 前 10 行内**首次出现单元格等于 `"Id"` 的行** = 字段名行 |
| **类型行** | 表头行的**上一行** |
| 数据行 | `Id` 行之后的所有行 |

```text
┌──────┬──────────┬──────────┬──────────┐
│ 备注 │ 英雄ID   │ 名字     │ 属性     │   ← 第 1 行：备注，被跳过
├──────┼──────────┼──────────┼──────────┤
│      │ int      │ string   │ int[]    │   ← 第 2 行：类型行（或 server/local 标记行）
├──────┼──────────┼──────────┼──────────┤
│      │ Id       │ Name     │ Skills   │   ← 表头行（含 "Id" 的行）
├──────┼──────────┼──────────┼──────────┤
│      │ 1        │ 剑士     │ [1,2]    │   ← 数据行
└──────┴──────────┴──────────┴──────────┘
```

### `server` / `local` 标记行

当第 2 行首列小写匹配 `server` 或 `local` 时进入 **`*` 保留模式**：

- 该行中值为 `*` 的列**才保留**
- 数据行的首列需为 `*` 才保留该行
- 存在 server 行时 `skipLine = 3`；否则打印 `【无server local模式】`

用于"同一份 Excel 同时产出本地表与服务器表"的场景。

### 类型支持

| 类型 | 说明 |
|------|------|
| `int` / `float` / `double` / `string` / `bool` | 基础类型 |
| `xxx[]` | 数组，Excel 里写 `[a,b,c]` |
| `list<xxx>` | 列表 |

空单元格的默认值：数值 `0`、`string` `""`、`bool false`、数组空数组。

string 数组解析带引号修复，引号数量为奇数时会报错。

!!! warning "首列必须是 `Id`"
    找不到 `Id` → `Debug.LogError("表格数据可能有错,没发现Id字段,请检查")` 并返回 `("{}", false)`。

### 多 Sheet

读**第一个** sheet。多 sheet 结构一致时会自动合并。`mSheet.Rows.Count < 1` 直接失败。

## 生成 C# 表类

`Excel2CodeTools` 把 Excel 转成 POCO：

| 项 | 约定 |
|----|------|
| 生成位置（本地表） | `Assets/Code/Game/Table/Local/<Name>.xlsx.cs` |
| 生成位置（服务器表） | `Assets/Code/Game/Table/Server/<Name>.xlsx.cs` |
| 生成到 Resource_SVN | `Assets/Resource_SVN/Table/Code/` |
| 命名空间 | `Game.Data.Local` / `Game.Data.Server` —— **必须 `Game.Data.*` 前缀** |
| 生成头 | `// <auto-generated> // Genera by BDFramework` |
| 热更标记 | `HotfixFileConfigLogic.IsHotfixFile()` 决定生成 `<Name>.xlsx.cs` 还是 `<Name>.xlsx@hotfix.cs` |

```csharp
// 生成结果示例（Assets/Code/Game/Table/Local/Hero.xlsx.cs）
namespace Game.Data.Local
{
    [Serializable()]
    public class Hero
    {
        [PrimaryKey] public int Id { get; set; }
        public string Name { get; set; }
        public string Level { get; set; }
        public int StarLevel { get; set; }
        public int NextLevel { get; set; }
        public string[] AttributeName { get; set; }
        public int[] AttributeValue { get; set; }
        public int[] Skills { get; set; }
    }
}
```

!!! danger "改命名空间会导致导表失败"
    `BuildTools_Excel2SQLite.CollectTableTypes()` 靠 `Namespace.StartsWith("Game.Data.")` 收集类型。

!!! danger "表名 = 类名，不含命名空间"
    `TableQueryForILRuntime` 生成 SQL 用 `type.Name`。**不同命名空间下的同名类会撞表。**

## 增量构建

逐文件 MurmurHash3 对比 `TableLog.Hash`，一致则跳过：

```text
【Excel2Sql】内容一致,无需导入
```

`TableLog` 表结构：`Path` / `Hash` / `Date` / `UnityVersion`。

`BuildSqlite(..., isUseCache: true)` 控制是否启用缓存判断。

## 产物与加密

| 产物 | 路径 | 加密 |
|------|------|------|
| client DB | `<root>/<platform>/local.db` | **SqlCipher 加密**（`SqliteLoder.Password`） |
| server DB | `<root>/server_data/server.db` | **不加密** |
| 构建信息 | `<root>/<platform>/package_build.info`（写 `tableSVC`） | — |

`LoadServerDBOnEditor` 中的原话：

```csharp
BDebug.Log("Server.db 不使用加密,否则服务器不好处理!!!");
```

**必须不加密**，否则服务器端读取需要集成 SQLCipher。

## 运行时读取

```csharp
// 单条件
var hero = SqliteHelper.DB.GetTableRuntime().Where("id = {0}", 1).FromAll<Hero>();

// 多条件
var ds = SqliteHelper.DB.GetTableRuntime().Where("id > 1").And.Where("id < 3").FromAll<Hero>();

// 排序 + 限制
var top = SqliteHelper.DB.GetTableRuntime().OrderByDesc("level").Limit(10).FromAll<Hero>();
```

## 常见故障

| 现象 | 根因 |
|------|------|
| `表格数据可能有错,没发现Id字段,请检查` | 前 10 行内没有单元格等于 `"Id"` |
| 导表后查不到数据 | 表类命名空间不是 `Game.Data.*`（`CollectTableTypes` 没收集到） |
| `SQLiteException: file is not a database` | 密码不对（`GameCipherConfigProcessor.Config.SqlitePassword`） |
| 两个表互相覆盖数据 | 不同命名空间下有同名类（表名 = 类名） |
| 每次都是全量导入 | hash 缓存失效（`TableLog` 被清或 `isUseCache: false`） |
| 数组字段值为空 | Excel 里格式不是 `[a,b]`；或引号数量为奇数 |
| 服务器读不了 server.db | 误用了加密（server.db **不应加密**） |
| `.xls` 文件不生效 | 只支持 `.xlsx` |
