# 前言

UFlux 是一套管理UI、帮助整理 编写UI业务的\*\*` 逻辑调度架构`.\*\*​

无论你使用NGUI、UGUI、FairyGUI等，都可以用这套框架进行调度\~

内置了很多功能：

如：

> 提供一套Flux ui管理机制(类似\*\*`MVI`**)
> 完善的UI管理,可配合任意NGUI、UGUI、FairyGUI等使用
> 完整的UI抽象：**`Windows`**、**`Component`**、**`State`**、**`Props`**、**`Store`**等...
> 支持**`UI管理`**、**`值绑定`**、**`数据监听`**、**`数据流`**、**`状态管理`\*\* 、\*\* ​`依赖注入`\*\*等..
