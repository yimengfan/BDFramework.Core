# 添加服务：

```c# 
//添加一个单例对象，每次获取都返回同一个对象  
public void AddSingleton<T>() where T : class
//Demo:
UIManager.Inst.AddSingleton<XXX>();    

//添加一个临时对象，每次获取都会返回一个新的对象
 public void AddTransient<T>(T obj) where T : class
//Demo:
UIManager.Inst.AddTransient<XXX>();     

```


# 依赖注入获取：

demo:&#x20;

Widnow\_DI.cs

Window中定义**Require**方法，则会自动对请求对象进行赋值\~

```c# 
    private Test1Service testService1;
    private Test2Service testService2;

    /// <summary>
    /// 这里是DI请求对象的接口
    /// </summary>
    /// <param name="service1"></param>
    /// <param name="service2"></param>
    public void Require(Test1Service service1, Test2Service service2)
    {
        this.testService1 = service1;
        this.testService2 = service2;
    }


```
