### 1.消息体的定义：

```c# 
  /// <summary>
  /// 测试消息
  /// </summary>
  public class UIMsg_Test: UIMsgData
  {
      /// <summary>
      /// 消息内容体
      /// </summary>
      public string MsgContent;
  }

```


**消息内容必须继承UIMsgData**

### 2.消息的发送：

i.主动向窗口发消息

```c# 
 var msg =new UIMsg_Test()
 {
     MsgContent = "我是一个测试消息!\n time:"+ DateTime.Now.ToLongTimeString()
 };

 UIManager.Inst.SendMessage(WinEnum.Win_UFlux_Test004, msg);

```


ii.打开窗口携带消息

```c# 
var msg =new UIMsg_Test()
{
    MsgContent = "我是一个测试消息!\n time:"+ DateTime.Now.ToLongTimeString()
 };

UIManager.Inst.ShowWindow(WinEnum.Win_UFlux_Test004, msg);

```


### 3.消息监听:

```c# 
[UIMessageListener]
private void TestMessage(Window_SimpleDemo004.UIMsg_Test msg)
{
  Content.text = "父窗口收到消息:" + msg.MsgContent;
}

```


1.消息用UIMessageListener 属性描述

2.每次派发到父窗口时，消息也会派发到子窗口

3.派发消息 只检测函数签名的 uisg的具体类型，比如：监听UIMsgData，发送UIMsg\_Test 则不会收到
